# Word Nest — 영어 단어 학습

브라우저에서 바로 쓰는 영어 단어 학습 웹 페이지입니다.  
플래시카드, 퀴즈, 단어장으로 기본 단어 20개를 익힐 수 있습니다.

## 실행 방법

1. `vocabulary.html` 파일을 더블클릭하거나
2. 브라우저로 파일을 열어 주세요.

별도 설치나 서버는 필요 없습니다.

## 기능

| 모드 | 설명 |
|------|------|
| **플래시카드** | 카드를 뒤집어 뜻·예문을 확인합니다. 「외웠어요 / 다시」로 학습 상태를 표시합니다. |
| **퀴즈** | 객관식 10문제로 뜻을 맞춰 봅니다. |
| **단어장** | 전체 단어, 발음, 품사를 한눈에 봅니다. |

- 외운 단어는 브라우저 `localStorage`에 저장됩니다.
- 플래시카드에서 `Space`로 뒤집기, `←` `→`로 이전/다음 이동이 가능합니다.
